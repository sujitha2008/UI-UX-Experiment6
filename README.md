# UI-UX-Experiment6

## Aim:

To apply various UX design techniques such as solution ideation, user story creation, scenario creation, flow mapping, and information architecture to understand user needs and develop a simple and user-friendly design.

## Algorithm:

1.Identify a suitable UX problem and generate multiple solution ideas using Crazy 8s or brainwriting.

2.Create user personas and write at least five user stories based on their goals.

3.Select a user story and create a narrative scenario including the user's context, environment, tasks, and emotional state.

4.Select a task and create a task flow/user flow diagram using standard symbols such as start, action, decision, and end.

5.Perform card sorting to organize related information into suitable categories.

6.Create an Information Architecture (IA) site map based on the categorized information.

7.Review all the designs to ensure that they are clear, logical, and user-friendly.

## Output:

1.Solution Ideation: Multiple low-fidelity ideas generated using Crazy 8s or brainwriting.

2.Creating User Stories: At least five user stories created based on user personas and their goals.

3.Creating Scenarios: A narrative scenario created for a selected user story, including the user's context, environment, tasks, and emotional state.

4.Flow Diagrams / Flow Mapping: A task flow or user flow diagram showing the sequence of actions and decisions.

5.Information Architecture (IA): A card-sorting result and a categorized site map showing the structure of the website or application.

## Result:

Thus, the five UX design activities — solution ideation, user story creation, scenario creation, flow mapping, and information architecture — were successfully performed. The activities helped in understanding user needs and developing a clear, organized, and user-friendly design.
